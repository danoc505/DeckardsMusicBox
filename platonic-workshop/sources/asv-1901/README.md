# The American Standard Version (1901), New Testament

The English beside the Greek New Testament (milestone 23).

- **What it is.** The American Standard Version of the Holy Bible, first published in 1901, as eBible.org
  prints it in its "BibleWorks import (VPL)" file: one verse per line, `BOOK chapter:verse text`, with the
  BibleWorks book codes (MAT, MAR, LUK, JOH ... REV).
- **Licence.** Public domain. eBible.org's notice, kept here as received (`eng-asv_about.htm`):
  "American Standard Version (1901) ... Public Domain ... This public domain Bible translation is brought to you
  courtesy of eBible.org."
- **Kept here.** `eng-asv_vpl-nt.txt` is the New Testament part of `eng-asv_vpl.txt` (the lines from `MAT 1:1` to the
  end), unchanged. `fetched.json` records the address, the time and the sha256 of the zip, of the file in it and of the
  part kept. The file is kept in the repository because eBible.org replaces its files when it updates them.
- **What the file leaves out.** "BIBLE TEXT ONLY. All formatting, paragraph breaks, notes, introductions, noncanonical
  section titles, etc., have been removed" (eBible.org's own description). So the ASV's margin notes are not here.
- **Square brackets** are as eBible.org prints them. Most mark words the translators added to make the English
  read (printed in italics in the 1901 book: "[that had been the wife] of Uriah", Matthew 1:6); a few mark a passage
  the translators bracketed (John 7:53 to 8:11).
- **Verses with no text.** Sixteen verses are printed as a number with no text (Matthew 17:21, Acts 8:37, Romans 16:24
  and others): the ASV moved them to its margin as not in the oldest manuscripts. The Workshop shows them as empty.
