**Untagged words.** A word is left untagged when GLAUx's words cannot be lined up with ours with certainty (see the README, *How GLAUx's tags are matched*); nothing is guessed. Most untagged, by share: Euthyphro 1.66%, Cratylus 0.72%, Phaedo 0.39%.

**Speakers.** The Greek text names speakers in Greek. The English name of each is read from the English file of the same work: where a section has the same number of changes of speaker in both, the names are paired in order, and each Greek name takes the English name it is paired with most often (`speaker_names` in build_db.py). A name never paired that way keeps its Greek form.
